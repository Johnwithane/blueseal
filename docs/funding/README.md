Research-backed, fact-checked funding strategy and draft application packs for Blue Seal —
a BC-based, pre-incorporation, pre-revenue, 2-founder verified-trades marketplace PWA.

*Built from a multi-source deep-research pass (adversarially fact-checked against official

rates, and deadlines change yearly, so re-confirm on each program's page before filing.*

## Start here — the 60-second version

> **One ~$400 action unlocks almost everything: incorporate in BC + put founders on T4 payroll.**

For a pre-revenue solo/duo founder, most marquee grants are gated and a few headliners are dead-ends. The real, non-dilutive plan:

1. **Incorporate in BC** (~$400) → unlocks SR&ED + most programs. *(`01`)*
2. **Run T4 founder payroll** → makes **SR&ED** worth ~60–65% of R&D salary back, refundable — your biggest prize. *(`04`)*
3. **Non-dilutive loans now:** **Futurpreneur** (≤$75K — Johnny, 37, is eligible) + **Community Futures** (≤$150K). *(`05`, `06`)*
4. **NRC IRAP** free advisor relationship → funding later. *(`06`)*
5. **New Ventures BC Competition** — $250K+ pool, no equity — prep for **Feb 2027** (2026 closed). *(`03`)*
6. **Wage subsidies** (SWPP open now / Tech Co-op / IRAP Youth) once you're ready to hire. *(`06`)*

**Don't chase:** BC IDMTC, Innovate BC Ignite, CDAP — confirmed non-fits (`02` Drop list).
